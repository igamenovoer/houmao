# Access Scope

The actor frame routes a request. Retained policy administration requires the verified execution owner's local authority. An enrolled gateway administrator has all supported gateway permissions subject to operation prerequisites. A verified initialized empty roster gives that same gateway authority to reachable callers. An unavailable or uninitialized policy establishes no open access.

Retained policy is scoped to a logical agent and execution context. A peer principal stays stable through key rotation, source relaunch, and changes to the source's operating-system account or tmux topology, provided the source can prove the currently enrolled key. The target gateway uses current retained policy when it admits work and can recheck permissions at the effect boundary.

## Select a Gateway

| Caller Context | Required Evidence |
| --- | --- |
| Verified owner-local gateway | Selected agent ID or name and the corresponding owner's live gateway record. |
| Remote gateway | Exact agent ID, trusted base URL, execution context ID, runtime generation, and listener presence ID. |
| Remote deployment using private TLS | CA bundle obtained independently from trusted deployment information. |
| Deployment using an encrypted local tunnel | Its trusted numeric loopback HTTP URL and the explicit remote identity coordinates. |

Take remote coordinates from trusted deployment or discovery records. Pass them with `--url`, `--context-id`, `--generation`, and `--presence` under the supported live command. The owner-local selection uses its verified recorded listener. Target and proof checks apply independently. A failed check calls for fresh trusted evidence, an explicit permission grant, or a precise blocker report.
