# Communicate With Managed Agents

- `houmao-mgr manual communicate mail` explains when and how to leave a durable handoff.
- `houmao-mgr manual communicate mailboxes` helps you prepare a store or bind an agent to its mailbox.
- `houmao-mgr manual communicate gateway` covers attachment, gateway control, and browser entry.
- `houmao-mgr manual communicate wakeups` explains how to configure and handle a notifier wakeup.
