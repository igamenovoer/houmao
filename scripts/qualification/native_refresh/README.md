# Native Refresh Qualification

These development utilities test installed native refresh controls before Houmao advertises them. Select the intended installed build explicitly. Each probe owns disposable native state and synthetic MCP servers; none submits a model turn or targets a tmux server.

- [DSH](dsh/README.md): native skill discovery, MCP/configuration reconciliation, HMR failure cases, and a controlled Web session continuity check.
- [Kimi Code](kimi/README.md): native server session reload for skill catalogs, MCP declarations, and one configuration field.
- [Codex and Claude Code](codex_claude/README.md): native control protocols, verified resource behavior, and scope/transport limitations.

The [preflight report](../../../context/plans/native-agent-home-refresh/preflight.md) records observed versions, design consequences, and remaining qualification gaps. Positive native-tool results do not establish a supported control connection from an existing Houmao backend. Run each README's commands from the repository root; JSON outputs belong in an ignored scratch directory.
