3. **Stale `fixture.py` `run.json` status after `houmao-mgr relaunch` (Scenario 4):** Once `fixture.py stop` writes `status: "stopped"` to `run.json`, reviving the agent with `houmao-mgr agents single relaunch` leaves `fixture.py` out of sync: `fixture.py prompt` fails with `Prompt requires a launched run` and `fixture.py stop` exits `0` without stopping the live relaunched daemon.
