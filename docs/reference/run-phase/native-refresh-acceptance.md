# Native Home Refresh Acceptance Map

This map covers all **112 delta scenarios** in `openspec/changes/archive/2026-11-17-add-native-agent-home-refresh/specs/`: 59 native-home/common-refresh, 23 scoped CLI, 14 DSH headless, and 16 passive-proxy scenarios. Scenario names below match those artifacts exactly. DSH headless and Web are primary; secondary-tool limitations do not become claims that the native tools lack reload facilities.

## Evidence and Qualification Boundaries

`Native` means an actual selected DSH 0.2.2-rc.3 process and controlled credential-free peer were exercised. `Hermetic` means deterministic model, service, client, or route tests. `Existing native regression` points to previously accepted DSH qualification, whose recorded run is preserved in the headless/Web acceptance references. `Native recipe` means the standalone preflight probe, rather than a managed production transport. `Limit` identifies a precise capability boundary; those rows do not claim a qualified native facility that has not been executed.

The final Web refresh bundle passed 28 cases across `test_refresh.py` and `test_refresh_gateway.py` in 68.12 seconds. It includes actual direct gateway, passive HTTP/client, scoped CLI, two distinct native agents, broad failed replacement, watcher/manual races, native child races, response loss, browser admission, retained loaded-skill history, unreachable MCP, and deadline expiry before later mutation. Both public native cases passed again after the final captured-identity guard. The provider peer received zero refresh-created model requests. ACP current-home acceptance separately exercises later ordinary prompts in one exact conversation. Native tests use explicit isolated tmux sockets with inherited `TMUX` and `TMUX_PANE` cleared; no shared localhost server cleanup is part of this evidence.

The gateway's initial 36 focused cases and passive proxy's initial 45 focused cases passed together (81 cases). The proxy's expanded identity-fence suite passed 77 cases, including a real HTTP conditional refusal; 179 existing passive regressions also passed after that change. Shared observer review passed 27 cases, shared strict model/strategy/privacy checks passed 38 cases, and active-home authority checks passed 26 cases. The separate manifest-refresh/relaunch native comparison passed both stored-default-new and explicit-exact cases in 26.23 seconds. Final repository-wide validation is reported separately from these scenario-level facts.

Final review added independent deadline and authority regressions in `test_native_refresh_deadline.py`, `test_native_refresh_http_authority.py`, and the scoped CLI/proxy suites. They cover slow preflight, exhausted remaining budgets, changed authority during ACP version inspection, reused healthy gateway ports, conditional HTTP 412 refusal, and mismatched returned observations. The combined HTTP-authority/scoped CLI suite passed 77 cases. These checks establish routing identity without adding proxy-local freshness decisions.

Repository checks on 2026-11-17 passed: `pixi run test` (4,467 passed, 14 skipped), `pixi run lint`, Pixi-managed Ruff format verification (977 files), `pixi run typecheck` (472 source files), strict documentation build, wheel/sdist build, and distribution metadata validation. The built wheel and sdist contain the refresh modules and native companion asset; the wheel excludes test and scratch trees. Strict validation of `add-native-agent-home-refresh` passed. ACP current-home/managed/fixture native acceptance passed 10 cases; the separate explicit-relaunch comparison passed two cases. The 112 scenario names in this map were checked against the delta artifacts.
