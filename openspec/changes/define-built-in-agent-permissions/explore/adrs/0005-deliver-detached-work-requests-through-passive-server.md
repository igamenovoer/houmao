# Deliver Detached Work Requests Through the Passive Server

A running agent can accept wrapped work while its gateway is detached when the passive server can verify its runtime and use a qualified native owner path. The passive server uses the same requester permission and attributed renderer as the gateway. It reuses ready-only owner dispatch for one immediate handoff.

## Status

Accepted.

## Consequences

Carol can ask ready, detached Bob to review a pull request without gaining direct prompt access. The request path is selected before submission and reports its own outcome. Mail remains available as a separate contact operation under Bob's recipient policy.
