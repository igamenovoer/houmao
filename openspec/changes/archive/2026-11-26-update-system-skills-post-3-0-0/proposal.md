# Proposal

## Why

Houmao has evolved substantially from the 3.0.0 release-candidate baseline (`v2.4.0..v3.0.0rc1` through `3.0.0rc8` at `HEAD`), adding DeepSeek Harness (`dsh`) support, unified run modes (`headless`, `service`, `tui`, `web`), execution-owner `--executor` bindings, layered `tool_params`, built-in agent permissions (`default-group`, `self-key`, `request`), versioned agent file edits (`--when-idle`), Stalwart intranet online mail, `houmao-cccc` chat/queue integration, durable usage records, `open-browser`, `houmao-mgr manual`, `project skills`, `project migrate`, `agents external`, and `admin executors|cleanup`. Across `src/houmao/agents/assets/system_skills/`, many existing skills omit these post-3.0.0 surfaces, contain live contract errors (`manifest.toml` missing `request`, stale "sixteen" count, wrong Qualified Modes table, broken v2 `/v1/mail` examples, `../reference/` paths, step-numbering and formatting bugs), and suffer from duplicated boilerplate or monolithic `SKILL-MAIN.md` files that violate `imsight-agent-skill-handling` conciseness and progressive-disclosure rules.

## What Changes

This change specifies updates to **existing runtime system skills ONLY** (`src/houmao/agents/assets/system_skills/public/**` and `manifest.toml`). Zero new skills, zero skill splits, zero skill merges, and zero skill retirements are proposed; all six `legacy/` loop directories and `legacy/catalog.v1.toml` remain frozen and unmodified to preserve SHA-256 `content_digest` matching in `src/houmao/agents/system_skill_lifecycle.py`.

1. **Close post-3.0.0 feature gaps and fix live drift across all 24 existing public skills and `manifest.toml`**:
   - Synchronize `manifest.toml` (`v5`): add `"request"` to `houmao-agent-messaging.commands`, align `houmao-agent-definition.aliases` (`authoring`, `deployment`, `batch`, `launch-instance`, `stop-instance` mapped to `SKILL-MAIN.md` canonical names) and `houmao-adv-usage-pattern.aliases` (accounting for both `self-notification` mode subpages and `-via-gateway-and-mailbox` stems), move `houmao-mailbox-mgr` account/message/`clear-messages` commands out of bare `aliases` into `commands` alongside `agent-binding-online` (with `mailbox-online=agent-binding-online` in `aliases`), and preserve the 6 standalone skills, 18 shared routines, and 26 `legacy_skills` SHA-256 digests intact.
   - Add missing post-3.0.0 surfaces across affected skills: `dsh` tool and credential CRUD (`houmao-credential-mgr`, `houmao-agent-definition`, `houmao-admin-welcome`), full `service` and `web` run-mode matrix (`houmao-agent-definition`, `houmao-agent-instance`, `houmao-agent-loop-pro`, `houmao-agent-loop-lite`), `agents single|self mailbox online` (`houmao-mailbox-mgr`, `houmao-agent-email-comms`), `built-in` permission ladder, `default-group set --passive-url`, `access self-key`, and recipient inbound policy (`houmao-agent-access`, `houmao-agent-email-comms`, `houmao-agent-messaging`, `houmao-interop-ag-ui`), `houmao-cccc` plugin configuration, delivery modes, and queue/chat operations (`houmao-agent-gateway`, `houmao-agent-messaging`, `houmao-adv-usage-pattern`, `houmao-operator-messaging`, `houmao-admin-welcome`), durable usage inspection and `service`/`web` endpoints (`houmao-agent-inspect`, `houmao-agent-gateway`), `agents external`, `--executor`, `open-browser`, `--tool-params`, `--headless-display-*`, `--reuse-home`, `--force`, `--agent-id-mode`, `--gateway-admin-seed`, `project skills`, `project migrate`, `houmao-mgr manual`, `admin executors|cleanup`, `system-skills` pack policy, and `MANAGED_PROMPT_HEADER_VERSION = 2` `<memo_cue>` and compact write receipts.
   - Fix live factual and link bugs: `houmao-shared-routines/commands/help.md` ("sixteen" to "eighteen"), `houmao-agent-definition/references/common/profile-lanes.md` Qualified Modes table, `houmao-adv-usage-pattern/commands/notifier-prompt-driven-mail-loop.md` (`schema_version: 3` and remove `include_body`), `houmao-agent-loop-pro`/`lite` `../reference/` to `../../references/`, `houmao-credential-mgr` step 9 numbering gap, `houmao-agent-instance/commands/cleanup.md` duplicate guardrail, `houmao-agent-access/commands/policy.md` missing blank line and informal "Bob/Alice" prose, `houmao-agent-messaging/commands/request.md` stub rewrite, `houmao-project-mgr/commands/launch-profiles.md` orphan resolution, and `houmao-agent-loop-pro/dev/design/` non-runtime directory removal.
2. **Apply `imsight-agent-skill-handling` structural and conciseness reductions**:
   - Decompose monolithic entrypoints (`houmao-ext-graphing` 282L, `houmao-interop-ag-ui` 262L, `houmao-process-emails-via-gateway` 169L, `houmao-memory-mgr` 142L) into lean `SKILL-MAIN.md` routers (~70-90 lines) backed by `commands/*.md` (each with numbered `## Workflow` and native-planning fallback) and `references/*.md`.
   - Strip cross-skill duplicated boilerplate inside self-contained shared routines: remove repeated 7-line `command -v houmao-mgr` launcher blocks, 10-line `Missing Input Questions` blocks, redundant `## Help` / `## Scope` / `## Subcommands` / `## Routing Guidance` repetition, obsolete `houmao-cli`/Pixi guardrails, and `"The trigger word houmao is intentional"` lines, adopting the concise pattern of `houmao-agent-access` (61L) and `houmao-agent-files` (68L) while preserving `system_skill_manifest.py` link containment.
   - Consolidate `houmao-agent-loop-pro/SKILL.md` and `houmao-agent-loop-lite/SKILL.md` (`## Upfront Planning Rule` duplication, `## Subcommands` + `## Routing` table merge into `Complex-procedure` three-split), add explicit `### Helper Subcommands` (`No helper subcommands are currently exposed.`) to `houmao-agent-files`, normalize `()` out of `Subcommand` table columns (`houmao-agent-access`, `houmao-agent-files`), and convert bulleted subcommand lists to clean tables (`houmao-credential-mgr`, `houmao-operator-messaging`, `houmao-adv-usage-pattern`, `houmao-mailbox-mgr`).
3. **Preserve all critical task-handling steps, safety gates, and packaging invariants**:
   - Keep `## Actor Frame Gate` on all 18 shared children, explicit vs `narrow-implicit` activation, admin vs agent audience boundaries, target gates, read-only boundaries, reply-hardening and fail-closed gateway/mailbox contracts, `<loop-dir>` and lite Markdown/SQLite boundaries, `system_skill_manifest.py` designator and link-containment checks, `metadata.houmao_version` and `metadata.skill_invocation_notation`, and frozen `legacy/*` SHA-256 digests.
